# Code of Conduct

## Our pledge

We want TapPay to be a welcoming, harassment-free project for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

We pledge to act and interact in ways that contribute to an open, welcoming, diverse, inclusive and healthy community.

## Our standards

Behavior that contributes to a positive environment:

- Being respectful, patient and kind
- Giving and accepting constructive feedback gracefully
- Critiquing code and ideas, not people
- Taking responsibility for mistakes and learning from them
- Focusing on what is best for the project and its users
- Searching for existing issues and pull requests before opening new ones, and closing the loop by linking your issue in every PR (`Closes #<number>`)

Unacceptable behavior:

- Harassment, insults, trolling, or derogatory comments
- Sexualized language or imagery, and unwelcome attention of any kind
- Personal or political attacks
- Publishing someone else's private information without permission
- Spam, self-promotion, or unrelated advertising in issues and pull requests
- Submitting deliberately malicious, plagiarized or low-effort bulk contributions
- Pressuring maintainers or other contributors for reviews or merges
- Any conduct that would reasonably be considered inappropriate in a professional setting

TapPay handles real money. Deliberately sharing or exploiting a vulnerability instead of reporting it privately, or sending funds-related instructions to other users, is also a violation.

## Scope

This Code of Conduct applies in all project spaces: issues, pull requests, discussions, code review comments, commit messages, and any official TapPay channel. It also applies when someone is representing the project in public, for example using the project name or posting from an official account.

## Enforcement

Maintainers are responsible for clarifying and enforcing these standards. They may edit, hide, lock or remove comments, commits, issues and pull requests that do not follow this Code of Conduct, and may temporarily or permanently ban a contributor for behavior they judge inappropriate, threatening, offensive or harmful. Reasons will be explained when it is safe to do so.

### Reporting

To report a violation, contact the maintainers privately. Use GitHub's private vulnerability and reporting tools, message [@tapxpay](https://x.com/tapxpay) on X, or reach a maintainer directly. Please include links, screenshots or other context. All reports are reviewed and investigated promptly and fairly, and the reporter's privacy is respected.

### Consequences

1. **Correction:** a private or public note explaining what was wrong and what is expected. A warning may follow.
2. **Warning:** a formal warning, with consequences for continued behavior and a request to stop for a set period.
3. **Temporary ban:** a ban from interaction in project spaces for a set period.
4. **Permanent ban:** a permanent ban from all project spaces for a pattern of violations or serious harassment.
